# Brightside PM Sim

**[▶ Play it now](https://sairajpulaparthi1.github.io/brightside-pm-sim/)**, free in your browser, nothing to install.

A browser game that teaches product management by doing it. You're the new Product Manager at Brightside, a (fictional) scheduling-software company for small salons and clinics. Walk the office, talk to your team, use real PM tools on your laptop, and live with the consequences.

- **Week 1:** customers are cancelling twice as fast as before. Find out why and fix it.
- **Week 2:** measure the launch, run an A/B test, survive a 2 a.m. outage, set prices, and plan the quarter.
- **Week 3:** set OKRs, run discovery, spec a feature, handle a big sales deal, and launch a new plan.

Start from the home page and jump to any week.

No experience needed. Every tool explains itself the first time you use it.

**Play:** [open the game](https://sairajpulaparthi1.github.io/brightside-pm-sim/), or open `index.html` from this repo in any modern browser. Progress autosaves in your browser; use **Save file** to keep a backup.

All companies, people and numbers in the game are made up.
